## 📊 Level 1: Excel Analytics Summary

### Executive KPIs
- **Total Sales:** **\$12,635,222.00**
- **Total Profit:** **\$1,467,721.69** (Profit Margin: **11.62%**)
- **Average Discount:** **14.29%**
- **Total Clean Records:** **51,271** (54 duplicates removed, 0 null values remaining)

### Key Analytical Takeaways
1. **Top Revenue Driver:** Technology category generates the highest profit margin (**13.98%**, \$663,337) and sales (\$4.74M).
2. **Regional Champion:** The **Central** geographic region leads globally with **\$2.82M (22.3%)** of aggregate sales.
3. **Core Segment:** The **Consumer** segment represents **51.5%** of global turnover (\$6.50M).
4. **Seasonal Trends:** Strong recurring annual spikes in **Q4 (September - December)**, driven by enterprise cycle ends and holiday shopping.
